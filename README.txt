VISIONX - SMART GLASSES WEBSITE

Files:
- index.html: Main website page
- css/style.css: Website design and responsive styles
- js/script.js: Website interactions and behavior

HOW TO OPEN:
1. Extract the ZIP file.
2. Keep the index.html, css folder, and js folder together.
3. Double-click index.html to open the website in your browser.

NOTES:
- The website includes embedded image data in the JavaScript file.
- Google Fonts are loaded from the internet, so those fonts require an internet connection.
- Cart, checkout, and contact form are front-end demo features. No real payment,
  order processing, email sending, or database is connected.
